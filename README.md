# Practice PRF prototype

Static browser-based training/documentation prototype.

## GitHub Pages

1. Upload all files and the `assets` folder to the repository root.
2. Open **Settings > Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Files

- `index.html` - page structure
- `styles.css` - visual styling and print layout
- `app.js` - calculations, navigation, local saving and interactions
- `assets/` - local image resources

## Important

This is a development/training prototype, not an approved clinical EPR. Do not store identifiable patient information without appropriate security, governance and clinical-safety approval.
