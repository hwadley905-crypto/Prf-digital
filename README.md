# Practice PRF v21

Version 21 uses a new, standalone NEWS2 overlay (`news21Overlay`) that does not depend on the previous NEWS2 modal or shared variables. The observation NEWS2 button calls a global `openNews21()` function directly. This is designed for Safari/iPad as well as desktop browsers.

Upload `index.html`, `app-v21.js`, `styles-v21.css`, and the complete `assets` folder. The v21 badge confirms the correct build is running. Replace the empty `New Incident.mp3` placeholder with the real audio.
